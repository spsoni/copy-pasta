# Changelog

All notable changes to the Copy-Pasta VS Code extension. Releases are tagged `vscode-vX.Y.Z`.

## [Unreleased]

## [0.1.2] - 2026-11-18

### Changed

- Marketplace display name **Copy-Pasta Files**: "Copy-Pasta" was taken. Commands and menus still say Copy-Pasta.

## [0.1.1] - 2026-11-18

### Changed

- The extension ID is `spsoni.copy-pasta-files`: the name `copy-pasta` was already taken on the VS Code Marketplace.
  0.1.0 was only released on GitHub, never on the Marketplace.

## [0.1.0] - 2026-11-18

### Added

- First release: Copy, Copy Encrypted…, Paste… with a preview, Paste from File…, Save as File…, a clipboard
  indicator in the status bar, and Clear from Clipboard.
- Reads and writes the same text as the Copy-Pasta plugin for JetBrains IDEs (format 2), checked against the shared
  conformance vectors and a JetBrains ⇄ VS Code interop test.
